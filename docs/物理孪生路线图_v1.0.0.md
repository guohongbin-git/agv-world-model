## 1. 定位

| 维度 | 现状 (仿真) | PhyWoM (物理) |
|---|---|---|
| 物理真值 | MuJoCo WarehouseCell | 真车 + 真传感器 |
| 证据 | 仿真观测通道 (11 帧采样) | 真传感器适配层 (同 schema) |
| 事务 | `commit_transfer` 单 SQLite 事务 | **不变** |
| 调度 | CP-SAT 100ms tick | **不变** (tick 放宽到 200ms) |
| 面板 | matrix.html (仓库/产线 tab) | **零改动** (状态契约同文件) |
| 消融 | B0/B1/B2/B3/B4 五组 1200 runs | 同五组, 故障注入→物理扰动 |

**不做**: 视觉 SLAM 重定位 (用 AprilTag 信标)、激光雷达 (用 ToF 阵列)、
ROS2 全家桶 (Micro-ROS 单向流即可)。

## 2. 适配层接口 (新增 `phy/` 包, 与 `sim/` 平行)

```python
# phy/evidence_bridge.py —— 仿真/物理唯一的分界线
class EvidenceBridge(Protocol):
    def sample_window(self, vehicle_id: str) -> list[EvidenceFrame]:
        """11 帧采样窗, 帧结构 = sim/observation 同 schema:
        {t_us, support_ratio, contact_amps[4], imu_stable, pose tag}"""

    def actuate(self, intent: MotionIntent) -> ActuationHandle: ...
    def fault_inject(self, scenario: str) -> None:
        """B0-B4 消融在真车上复现: 滑托=降低压感阈值告警缺失/
        丢步=注入编码器偏差/断电=继电器切电 (对应 D02/D03/D06)"""

# 仿真侧零改动: World.commit_transfer 只认 EvidenceFrame 列表
```

- **车端** (ESP-IDF + Micro-ROS 或 ESP-NOW 裸协议): 200Hz 采样
  IMU/编码器/ToF/电流, 50Hz 打包上行; 下行 MotionIntent (v/ω/举升位置)
- **通信**: 阶段 1-2 用 ESP-NOW (延迟 <5ms, 无路由依赖); 阶段 3 多工位
  升 MQTT (QoS1); 断链默认**安全停 + 证据窗封存** (对应恢复对账)
- **视觉**: 单固定相机 + AprilTag 2 (货架层/车顶/托盘底三位一体),
  30fps, 位姿解算在 PC 端 (OpenCV), 车端零视觉算力

## 4. 证据五门 → 传感器映射 (阶段 1 详表)

| 门 (EvidenceVerdict) | 仿真判据 | 物理判据 | 阈值移植 |
|---|---|---|---|
| 承托率 ≥95% | 4 角接触力 | 薄箔压感×4 分压 | 逐点标定 (砝码 5 点) |
| 卸载 ≤5% | 撤销期接触 | 压感衰减 + 电流跌落 | 沿用 5% |
| 0.5s 稳定窗 | 位姿方差 | IMU 角速度+加速度方差 | 同方差算式 |
| 静止 | qvel≈0 | 编码器增量=0 持续窗 | 同 |
| 位姿 ≤10mm | 真值位姿 | AprilTag (1:10 下 tag 精度 ±3mm) | 沿用 10mm |

**标定协议**: 每传感器 5 点标定入 `phy/calibration/*.json`,
`EvidenceBridge` 加载后才能出帧; 未标定 = 门判 `E_UNCALIBRATED` (拒绝)。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 打印件举升刚度不足 → 位姿门误拒 | 门架加三角筋; PETG; 失败样例直接进 ESR-Loop 结晶 |
| AprilTag 遮挡 (举升时车顶 tag 被货挡) | tag 移至车头/车尾双侧 + 层位 tag 冗余 |
| ESP-NOW 2.4G 拥挤 | 信道扫描固定 + 阶段 3 迁 MQTT |
| 轮式里程计漂移 | 路径仅作规划, 位姿门**只认视觉** (同仿真"决策侧零真值"红线: 视觉即观测) |
| 工期 | 三阶段独立验收, 任一阶段可发表/演示 |

## 7. 与 ESR-Loop 的闭环 (本路线图的灵魂)

物理事故 → `phy/incidents/` 目录 (同 incident 四件套格式) →
ESR-Loop 五拍: 结晶真实根因 (公差/打滑/丢步) → 技能条目 →
进化门修订证据契约 (如新增"皮带打滑门") → 消融回放。
**仿真里 1200 runs 炼出的故障矩阵, 在真车上开始长自己的版本。**
