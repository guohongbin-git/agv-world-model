# 多体接触发散故障链：完整取证记录（DetFix run1–run5）

来源：`reports/detfix/run{1..5}*.json`（1 kHz 环形缓存插桩 + 全局最大力对追踪 + 触发式转储），2026-10-12。
这是 M2 矩阵仓库 8 车并发的**系统性物理缺陷**完整因果解码，也是 Paper I
"物理-事务不对称性"的工程注脚：每一环都能在账本上留下可审计的错误，
但只有 1 kHz 插桩才能还原链条。

         叉顶进入的是托盘中心板上方而非叉孔

## 最初的推动力（真正的根因, run3 定位）

**F02 的叉偏 13mm 不是它自己的错**：F03 的导航路径碾过 `row:2` 行线
（途经 F02 的**活跃拣选区**）——此时该 lane-lock 已被释放（导航到位即放），
行线穿活区没有联锁。F03 物理挤碰 F02 底盘（11–21 N 接触）→ 插入中的
叉被顶偏 13mm → 上述全链。

**修复**：行线道岔联锁（job 持有期间活区 lane 不释放）。

## 方法论沉淀

1. **故障链不是链式报告出来的，是 1 kHz 环形缓存 + 触发转储还原的**——
   常规日志只看到"NaN at t=558"，往前 400 秒的因果全靠插桩。
2. **跨车接触（11 N 级）即可毁掉 13mm 级装配公差**——多车并发的安全
   间距必须进锁语义（行线道岔），不能只靠路径几何。
3. **"无货时的对中跳过"是反模式**——空台到达同样要对中（销-垫块干涉
   与有无托盘无关）。
