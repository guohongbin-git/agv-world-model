「具身智能解决的是信息问题」
—— 文献裁决与产品理论

本页由世界模型服务与 GPT 会话独立检索、联合评审生成（2026-10）。 对应仓库文档：docs/agentic_world_model_literature.md、docs/agentic_twin_design.md。
裁决：论点成立。 omp 与 ChatGPT 各自检索文献后独立得出同一结论—— 具身智能的深层价值在于把物理执行变成持续可观测、可验证、可学习的过程； 但表述需精确化：不说"机器人第一次闭合反馈回路"（控制论早已建立反馈思想）， 说"将物理执行证据系统性地纳入企业级决策学习回路"。
原始论点：再好的 plan，人类执行时都有偏差，而偏差信息的收集是不完整的 （忘了报、测不准、没有动机记录），导致 plan 无法充分优化、迭代。机器人把每次执行变成 可测量、可归因、可审计的数据，第一次让 计划→执行→偏差→学习 的闭环真正闭合。

二、必须精确化的地方（两方合并）

  1. 所有物理执行都有不确定性——偏差非人类独有（sim-to-real gap，Tobin 2017）。 差别不在有无偏差，而在偏差可测、可归因、可学习：人的偏差是信息黑洞，机器人的偏差是数据资产。
  2. 信息优势属于"感知+记录+可查询"的系统，不属于泛自动化——盲目执行程序的工业机器人同样丢信息。 本页这个演示里：观测→SQLite 事务→事件账本，缺一不可。
  3. 记录偏差 ≠ 归因 ≠ 学习（Pearl 2009）： "晚到 20 秒"可证明，"因为锥桶"不能自动成立。闭环要拆六段： Plan→Act→Observe→Compare→Explain→Learn。
  4. 人工记录并非全无价值：人提供传感器拿不到的语义与情境——所以架构保留人作为知识来源、 异常解释者与最终授权者（Bainbridge 1983《Ironies of Automation》的警示）。
  5. 数据多 ≠ 计划好：只有经质量治理、可验证、进入决策更新的数据才推动改善。

三、产品理论：Execution Intelligence（执行智能）

层次回答的问题谁能做到
L1 执行可观测性实际发生了什么？观测多可信？传统控制系统
L2 决策可追溯性当时基于什么信息与约束做了什么决定？业务系统 / 事件溯源
L3 跨任务决策学习为什么产生偏差，下一次怎样做得更好？差异化所在

每次策略改进必须能回答六问：旧策略是什么 / 观察到哪些偏差 / 改了什么 / 用什么测试验证 / 改善多少 / 引入什么新风险。学习链条： Physical Execution → Execution Evidence → Decision Memory → Policy Improvement。

最有价值的资产不是第 100 次成功搬运，而是"第 37 次为什么失败、 改派是否真的比等待好"。

四、本演示即论点的可执行检验

  • 这个页面所在的世界模型：库存只在物理证据成立时提交（离梁承托率、退叉脱离观测）， 事务与事件全部落 SQLite 账本——L1/L2 已在线运行。
  • Agent 是唯一指令入口，但不能触碰库存写入——"agent 可以改变计划， 不能改变未经物理验证的事实"。
  • 下一步（P3/P4）：锥桶 + 激光雷达点云（禁上帝视角）+ 重规划/改派 + 消融门禁—— 关感知必撞桶、关调度必停滞，用可预测失败证明智能是真的。
