## 6. 关键物理偏差记录

### 6.1 收拢包络 (设计 981)

设计给的「基座XY半径70mm」被实测为**可达**, 不是不可达:
`sim/solve_stow.py` 数值求解得 `q=[0, -1.3528, -0.2962, 0, -0.3056, 0]`,
臂体水平最大半径 **42.3mm** (设计 70mm 内), 最高点 526.0mm (限 600mm),
活动连杆最低点 70.0mm ≥ 托台面 55mm (不穿台)。

追查过程中发现 `<position>` 执行器漏写 `ctrlrange`, MuJoCo 默认 `[0,0]`,
每次 `mj_step` 把 ctrl 夹到 0 —— 关节几乎不动。**在此之前所有抓取、
收拢与轨迹结果都来自一台欠驱动的臂**, 修复后收拢包络才降到 42.3mm。

### 6.2 T06 单车白模接力上限

`sim/forklift_cell.py` 是单车白模 (一个 freejoint 托盘 + 一根横梁 + 一对叉)。
连续复用同一单元实测: r0–r3 完全一致 (托盘 4100mm、叉承托 1.000、梁 0.000),
r4 托盘下沉 1.5mm 并压上横梁 (接触穿透 1.2µm), r5 起不可逆地留在梁上。

故 T06 分两层验证: 调度/库存层跑满 50 轮 (每轮新装配物理单元),
物理保持上限写成显式常量 `SUSTAINABLE_RELAYS = 4`。
**未放宽任何阈值** (0.90 / 0.10 / 1µm 保持原值)。详见 `t06_relay_limit.md`。
